# NutraLiving - Sistema de Login

Sistema de autenticação desenvolvido como projeto de aprendizado, utilizando Node.js, Express e Supabase.

## Tecnologias utilizadas

- HTML, CSS e JavaScript
- Node.js
- Express
- Supabase
- Bcrypt

## Funcionalidades

- Cadastro de usuário com validação de senha em tempo real
- Login com autenticação segura
- Senhas criptografadas com bcrypt
- Feedback visual para o usuário

## O que aprendi

- Criar um servidor com Express
- Proteger variáveis sensíveis com dotenv
- Criptografar senhas com bcrypt
- Organizar o código em módulos (auth.js, ui.js, supabase.js)
- Arquitetura em camadas separando frontend e backend
- Versionamento de código com Git e GitHub

## Como rodar localmente

1. Clone o repositório
2. Instale as dependências com `npm install`
3. Crie um arquivo `.env` com suas credenciais do Supabase
4. Rode com `npm start`
5. Acesse `http://localhost:3000`
